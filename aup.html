Acceptable Use Policy (AUP)

LAST UPDATED: AUGUST 15, 2026 · SPECIFICATION 1.0

This Acceptable Use Policy ("AUP") defines prohibited activities and usage standards when using the PromptMatrix cloud infrastructure, API serving endpoints, and developer tooling.

1. Prohibited Content & Applications

You agree not to use PromptMatrix to store, version, or serve prompts designed to:

  • Generate, distribute, or facilitate malware, ransomware, or exploit payloads.
  • Generate Child Sexual Abuse Material (CSAM) or non-consensual explicit content.
  • Facilitate unauthorized surveillance, fraud, phishing campaigns, or identity theft.
  • Violate applicable laws, regulations, or third-party intellectual property rights.

2. Infrastructure & API Abuse

To preserve platform reliability for all engineering teams, you must not:

  • Attempt to bypass rate limits or security headers via distributed botnets or forged IP addresses.
  • Probe, scan, or test the vulnerability of PromptMatrix systems without explicit written permission from our security team.
  • Reverse engineer, decompile, or extract proprietary cloud components that are not part of the MIT-licensed open-source repository.

3. Enforcement & Suspension

Violations of this AUP may result in immediate suspension or termination of workspace API keys without prior notice. If you suspect an AUP violation, contact us at jachinchsaikiasonowal@gmail.com.
